# Mod 管理器

一个自己写的游戏模组管理器。

## 这是什么

基于 Electron + Vue 的桌面应用，用来管理游戏模组：扫描游戏目录、安装模组、卸载模组、排序、编辑模组信息。

## 已完成

- 首页
- 游戏管理：添加游戏、扫描游戏目录
- 模组管理：
  - 扫描模组
  - 安装模组
  - 卸载模组
  - 排序
  - 编辑模组信息（进行中）

## 未完成 / 已知问题

- 编辑模组信息功能还没写完
- 模组封面显示有问题
- 部分无关文件会被丢进游戏根目录（需要修）
